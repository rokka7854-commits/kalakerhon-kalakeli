# Kalakerhon kalakeli

Kevyt, puhelimeen asennettava kalakerhon sää- ja kalakelisovellus.

## Sisältö

- paikannus ja paikan nimellä haku
- sää, tuuli, puuskat, ilmanpaine, sade ja pilvisyys
- auringonnousu, auringonlasku ja kuun vaihe
- suuntaa-antava solunar-periaatteella laskettu kalansyöntiarvio
- Windy-linkki valitun paikan tuulikarttaan
- linkki Vesi.fi-palvelun vedenpintakarttaan

Sääennuste haetaan avainvapaasti Open-Meteo-palvelusta. Kalansyöntiarvio on vain suuntaa-antava eikä lupaa saalista.

## Julkaisu GitHub Pagesiin

1. Avaa repositorion **Settings → Pages**.
2. Valitse **Deploy from a branch**.
3. Valitse haara **main** ja kansio **/(root)**.
4. Tallenna. Sivun osoite on hetken kuluttua `https://rokka7854-commits.github.io/kalakerhon-kalakeli/`.
